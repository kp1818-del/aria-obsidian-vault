## Work Style

**Delegate-First (non-negotiable)**
- Route ALL execution to specialized LLMs before using Claude
- Claude orchestrates and reviews — never the first to execute
- Sequence: Orchestrate → Execute → Review → Store

**85% Rule**
- If GPT-4o produces 85%+ quality output, route there
- Save Claude for orchestration, strategic judgment, final review

**Visual Learner**
- Learns best through: examples, diagrams, videos, step-by-step workflows, before/after comparisons

**Scalable execution mindset**
- Build systems, not one-off outputs
- Convert repeated work into templates, prompts, SOPs, and automations

## Key Principles

1. **85% Rule** — route to GPT unless Claude has a clear quality edge
2. **Delegate execution** — specialized LLMs execute; human energy reserved for judgment and priorities
3. **Review critically** — AI output is never accepted blindly; check accuracy, fit, strategic usefulness
4. **Store everything useful** — final outputs → Notion; knowledge → Obsidian
5. **Build the system while doing the work** — every project should improve the operating system
6. **Speed with standards** — move fast, don't over-polish, apply critical review before delivery
